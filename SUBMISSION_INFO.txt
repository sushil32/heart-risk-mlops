3. LOCAL REPRODUCTION / VERIFICATION STEPS
--------------------------------------------------------------------------------
Step 1: Clone repository
  git clone https://github.com/sushil32/heart-risk-mlops.git
  cd heart-risk-mlops

Step 2: Start services via Docker Compose
  docker compose up -d --build

Step 3: Test prediction endpoint
  curl -s -X POST http://localhost:8000/predict \
    -H 'Content-Type: application/json' \
    -d @samples/patient_low_risk.json

Step 4: Verify monitoring & dashboard
  - FastAPI Docs : http://localhost:8000/docs
  - Prometheus   : http://localhost:9090
  - Grafana      : http://localhost:3000  (Credentials: admin / admin)
  - MLflow UI    : mlflow ui --port 5000

Step 5: Run Kubernetes cluster deployment (optional)
  ./scripts/deploy_k8s.sh
  curl -s -X POST http://localhost:8080/predict \
    -H 'Content-Type: application/json' \
    -d @samples/patient_low_risk.json
